# Seasonal Agriculture Performance Analysis

## Project Overview

Seasonal Agriculture Performance Analysis is a data analysis project developed as part of the VOIS AICTE Batch 1 2026–2027 Major Project.

The project analyzes agricultural activities across different seasons, crops and geographical areas. It studies crop yield, production, resource usage, environmental conditions and economic performance.

The main aim is to identify seasonal patterns, compare crop performance and understand the relationship between agricultural resources and outcomes.

## Objectives

- Analyze the agricultural dataset.
- Clean and prepare the data for analysis.
- Compare agricultural performance across seasons.
- Study crop-wise yield, production and profit.
- Analyze resource usage such as water, fertilizer and pesticides.
- Examine environmental factors such as rainfall, temperature and humidity.
- Identify relationships using statistical analysis and visualizations.
- Provide recommendations for better agricultural planning.

## Dataset

The dataset contains agricultural information related to:

- Crop and season
- State and district
- Farm area
- Rainfall and temperature
- Soil conditions
- Fertilizer and pesticide usage
- Irrigation method
- Crop yield and production
- Cost, revenue and profit
- Water usage and efficiency
- Disease and pest risk

## Data Preparation

The dataset was checked for missing values and duplicate records.

Missing numerical values were handled using median imputation, and duplicate records were removed before performing the analysis.

## Key Findings

- Kharif was the best-performing season based on average yield.
- Kharif recorded the highest average profit.
- Sugarcane recorded the highest average yield and profit among the crops.
- Water efficiency showed a strong positive relationship with crop yield.
- Production and revenue were also strongly related to agricultural performance.
- Seasonal and crop-wise differences were observed in yield, profit and resource utilization.
